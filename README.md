# Variation in 24 NF-kB regulatory genes across human populations
Author: Reuben S. Maghembe. Public source-derived data and code release (2026-10-29).
The study examined 24 genes across four pathway modules in 49 primary populations (80 descriptive labels). Global Kruskal-Wallis H=2.7172106452422824, 100000 permutations, p=0.45586544134558654; corrected pairwise and sensitivity analyses were nonsignificant. Strict phased data: 980 haplotype rows (52 identities) across IKBKG, RBCK1, TNIP1; local LD: 1471 numeric r2 values plus 979 nonevaluable NA entries. These are not proof of functional adaptation or clinical causality.
`data/S1_file.xlsx` and `data/S2_file.xlsx` are source-derived workbooks; `data/tsv/` contains 14 checksum-pinned scientific sheet mirrors. Code/configuration comprise 119 files from the exact R15 parent; one Crossref user-agent contact adjustment was made. Original individual-level genotype/VCF/BCF, participant IDs, and clinical records are not redistributed. This release is **not an end-to-end fully executable Phase A-F reproduction**.
