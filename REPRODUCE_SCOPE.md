# Reproducibility boundaries
This is an author-controlled historical 119-file source snapshot, not a complete executable data-to-figure pipeline. Some original environment inputs, source accessions and Phase F execution receipts are not fully attested. No analyses were rerun for this release. Datasets include the minimum strict-primary haplotype and local-LD table values; 10800 wider-context LD rows are outside this release. NA is not zero; NQ denotes a scoped nonquery. Code is supplied for audit/reuse with actual source and environment requirements documented, not as proof of a full replay.
